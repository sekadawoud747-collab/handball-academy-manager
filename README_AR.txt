Handball Academy Manager — النسخة الأخيرة من المشروع

المشروع يحتوي مصدر تطبيق Android وواجهة عربية ودمج Firebase Authentication وCloud Firestore، مع قواعد حماية ودوال إدارة حسابات الكباتن.

قبل استخدام بيانات حقيقية: افتح FIREBASE_CONNECT_AR.txt ونفّذ إعداد المدير ونشر القواعد والدوال. المزامنة الفعلية لن تعمل قبل هذه الخطوات.

لبناء APK: افتح مجلد المشروع في Android Studio، انتظر Gradle Sync، ثم اختر Build > Build APK(s). ملف APK غير مرفق لأن بيئة البناء هنا لا تحتوي Android SDK/Gradle المطلوبين.

الدخول الحالي بالبريد الإلكتروني وكلمة المرور؛ تسجيل الدخول عبر SMS غير موصل في هذه النسخة.
